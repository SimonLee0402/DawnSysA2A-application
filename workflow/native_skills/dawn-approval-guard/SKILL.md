# Dawn Approval Guard

This is a Dawn native builtin skill.

Purpose:
- insert human approval into sensitive automation paths
- guard payment authorization and AP2-linked actions
- keep high-risk execution under explicit operator control

Primary local surfaces:
- Approval Center
- `/app`
- `/console`
- governed task execution flows

Notes:
- this is a native Dawn workflow skill, not a Wasm artifact
- it is always available on the local system once Dawn is installed
